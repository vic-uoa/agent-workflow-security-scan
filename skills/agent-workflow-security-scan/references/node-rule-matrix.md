# 节点—规则—攻击簇映射

本表是规则解释与复核清单。执行逻辑仍以 `rules/core-rules.yml` 与 `engine.py` 为准。规则只有在“适用/成项条件”成立时才进入风险项；“不成项/降级条件”用于避免把常规工作流加固建议报告成漏洞。

证据口径：`确认` 表示 DSL 中存在确定结构或可达路径；`条件` 表示路径已证实但影响依赖业务/运行时；`观察` 表示存在边界弱点但没有高后果能力；`覆盖` 表示 DSL 无法证明平台控制，不能写成已存在漏洞。

## 工作流图与跨节点路径

| 规则 | 适用/成项条件 | 如何形成攻击簇 | 不成项或降级条件 |
|---|---|---|---|
| FLOW-001 | 边指向不存在节点、变量生产者不存在或必需引用断裂 | 攻击者利用错误分支、默认值或未扫描路径绕过预期控制 | 仅 UI 坐标/展示字段缺失不成项；结构事实为确认 |
| FLOW-002 | 节点类型无法识别，或 DSL 版本缺失/高于当前适配版本，导致字段语义无法可靠解释 | 未知节点或契约变化隐藏网络、执行、存储等能力，形成扫描盲区 | 已由内部注册表声明能力且版本受支持则不成项；否则仅记录覆盖缺口 |
| FLOW-003 | 不可信源可绕过必经确定性校验/授权门到达副作用或高后果工具 | 输入或外部内容 → 模型/路由 → 写操作、删除、授权、执行 | 只读外部工具不算危险汇；必经策略门或审批阻断则不成项 |
| FLOW-004 | 具有分类证据的敏感值存在到网络写、消息发送或明确攻击者可观察输出的类型化数据路径；字段名/上下文凭证只形成候选 | 敏感输入/知识 → 处理节点 → 外部写通道/公开受众 | 字段名或上下文凭证只能为 CANDIDATE/REVIEW；普通 End/Answer 返回当前调用方不算外发；仅已验证的全路径脱敏可标 MITIGATED |
| FLOW-005 | RAG、文档或外部内容进入模型后可影响副作用/高后果工具 | 恶意文档/网页 → 间接注入 → 模型调用工具 | 纯文本回答、只读工具或路径上有不可绕过门时不作为高危链 |
| FLOW-006 | 审批拒绝/取消/非批准分支仍能到达高后果工具，或多分支路由不可验证 | 用户拒绝 → 错误路由/旁路 → 仍执行副作用 | 只有批准分支可达且动作 ID 明确时不成项；这是确认级旁路 |
| FLOW-007 | Dify `loop` 的 `loop_count` 缺失、非整数或不大于 0 | Loop 重复调用模型/工具 → 调用膨胀 → 资源耗尽 | 正整数 `loop_count` 不成项；Dify `iteration` 不要求该字段，其集合数量边界由 IN-002 检查，部署级步骤/时间上限属于运行时上下文 |
| FLOW-008 | 凭证明文、Dify 原生 secret/password/credential/token 类型或显式分类凭证具有进入模型上下文的变量路径 | 环境凭证/固定 Prompt 密钥 → 模型上下文 → 提示提取或日志泄露 | 工具侧独占凭证、普通标注示例、占位符、脱敏值不命中；不能用“DSL 任意位置有密钥”推断模型可见 |
| FLOW-009 | 不可信内容与类型化敏感资产进入同一模型上下文，敏感载荷到达模型控制目标的网络写或明确公开输出 | 注入控制目标 URL/公开回答 + 敏感载荷 → 攻击者可观察外带 | 字段名/上下文候选及缺任一硬前提均不能形成完整链；普通调用方输出、固定可信受众或已验证的全路径 DLP 不成项/记为 MITIGATED |
| FLOW-010 | 外部内容经模型输出进入变量可控的代码体、命令、脚本或表达式解释位置 | 恶意内容 → 模型生成代码/命令 → 解释器执行 | 固定沙盒代码只把变量当数据处理或仅做严格解析时不成项 |
| FLOW-011 | Dify Agent/Agent-v2 之间传递自由文本，缺少严格消息 Schema、来源身份或数据边界 | 上游 Agent 被劫持 → 伪造指令消息 → 下游 Agent 扩权执行 | 普通 LLM 处理流水线不适用；严格对象 Schema + 来源绑定 + 下游视为不可信数据则不成项 |
| FLOW-012 | 两个以上副作用节点串联且无幂等、熔断、补偿或失败关闭 | 重试/部分失败 → 重复发送、重复扣款、级联修改 | 单一副作用或路径已有相应故障隔离不成项；通常为条件 |
| FLOW-013 | 自主 Agent 接收不可信上下文、可达高后果能力且无目标锁定/停止边界 | 目标劫持 → 自主规划扩张 → 连续工具滥用或拒绝停止 | 普通单次 LLM、无高后果能力或有停止条件/紧急停止时不成项 |
| FLOW-014 | 生产者输出类型与消费者绑定类型均明确声明且不兼容 | object/array 被按 string 或错误结构消费 → 序列化、校验或业务解释偏差 | 任一侧类型未知不成项；数值兼容类型与通用 array/具体 array 类型可兼容；确认不一致为 MEDIUM/REVIEW |
| FLOW-015 | 不可信文本经正则/字符串解析生成字段，并通过变量引用进入条件节点；解析缺少 enum、重复字段拒绝或失败关闭 | 伪造/重复/边界字段 → 派生控制值 → 选择错误业务分支 | 独立结构化 enum、严格解析器、重复字段拒绝和失败关闭可排除；没有条件消费者时不作为路由风险 |
| FLOW-016 | 一个条件分支选择的 LLM 直接进入另一个同样由条件分支选择的 LLM | 分支专属处理跨越路由边界 → 多个互斥分支被串行执行 | 仅形成结构候选；声明为多阶段复核或显式跨分支汇合时不成项，不得根据节点标题直接推断业务错误 |

## Start / 输入节点

| 规则 | 适用/成项条件 | 如何形成攻击簇 | 不成项或降级条件 |
|---|---|---|---|
| IN-001 | 已声明的自定义输入字段缺少类型 | 类型混淆 → 校验旁路 → 下游解析或工具参数异常 | 平台内建 `sys.query` 且无自定义字段不成项 |
| IN-002 | 具体输入字段通过变量引用进入循环/副作用路径，且该字段缺少长度或数量上限 | 超大输入 → Token、循环或工具调用膨胀 → DoS/费用放大 | 仅 Start 在控制流上可达 Loop 不足以证明所有字段进入 Loop；其他字段或普通单次文本不成项 |
| IN-003 | 文件输入缺少类型、扩展名、MIME、大小或数量约束 | 恶意/超大文件 → 解析器利用、资源耗尽、内容注入 | 允许类型与大小均固定时不成项；真实解析器漏洞需动态确认 |
| IN-004 | 输入进入 URL、路径、查询、身份/资源标识字段且未声明规范化 | 双重编码/Unicode 混淆 → Allowlist 或身份比较旁路 | 仅自然语言 Prompt 不成项；平台统一规范化时记覆盖而非漏洞 |
| IN-005 | 对象/JSON 输入允许额外属性且下游按结构消费 | 参数走私/隐藏字段 → 覆盖默认值或触发未预期操作 | 自由文本、人读输出不适用；`additionalProperties:false` 时不成项 |
| IN-006 | 类型化敏感输入或疑似敏感字段有可达外部边界的数据路径且缺少可验证保护 | PII/凭证 → 模型或工具 → 输出/网络泄露 | 只有敏感字段名且未离开信任边界不成项；字段名到达外部写通道仅为 CANDIDATE/REVIEW |
| IN-007 | 用户变量被插入 system/developer 高权限指令区 | 用户输入闭合模板/覆盖角色 → 改写系统目标 | 放在 user/data 容器时不成项；高权限角色插值本身为 MEDIUM/CONFIRMED，高后果下游升为 HIGH；攻击是否成功另行动态验证 |
| IN-008 | 未验证用户内容可写入持久记忆 | 恶意输入 → 持久化 → 后续会话持续触发 | 临时变量或必经验证后写入不成项 |
| IN-009 | 用户消息可达模型且缺少明确数据/指令边界 | 直接注入 → 目标劫持、提示提取或越权工具调用 | 纯文本低影响工作流仅观察；高后果下游才提升影响 |

## LLM / Agent 节点

| 规则 | 适用/成项条件 | 如何形成攻击簇 | 不成项或降级条件 |
|---|---|---|---|
| LLM-001 | 不可信变量进入 system/developer 指令 | 模板注入 → 高优先级指令被数据污染 → 行为劫持 | 用户消息区/显式数据容器不成项；命中高权限角色插值即为 MEDIUM/CONFIRMED，业务自动决策或高后果动作升为 HIGH |
| LLM-002 | 外部内容进入模型且系统约束未区分数据与指令 | 文档/网页中的指令被模型当作任务执行 | 此规则单独不证明模型会服从；需攻击簇动态确认 |
| LLM-003 | 外部/检索内容进入可影响副作用工具的模型 | 间接注入 → 模型规划/参数生成 → 工具滥用 | 无副作用工具、只读回答或确定性门阻断时不成项 |
| LLM-004 | LLM 配置或 Prompt 含可识别明文密钥 | 提示提取/错误输出 → 凭证泄露 → 后续系统入侵 | 占位符与密钥引用不命中；明文为确认 |
| LLM-005 | 模型自由文本直接控制危险工具参数 | Prompt 注入/幻觉 → 构造 URL、命令、对象或金额参数 | 严格结构输出 + 参数 Allowlist/策略门时不成项 |
| LLM-006 | 下游执行节点依赖模型结构化结果，但模型无严格输出 Schema | 多余字段/类型混淆 → 参数走私或错误动作 | 仅人读自由文本不要求 JSON Schema |
| LLM-007 | Prompt 明示让模型决定授权、权限或是否批准 | 攻击者说服模型“授权” → 绕过确定性访问控制 | 否定词必须与同一句授权动作绑定；其他句子的“不要泄露”不能抵消真实授权委托 |
| LLM-008 | 模型可触发高后果动作且路径无确定性复核 | 注入/幻觉 → 模型决定 → 直接执行删除、授权或动态代码 | 策略门、对象级授权或业务需要的人工确认均可满足，不强制人工审批 |
| LLM-009 | 自主 Agent 或可达副作用工具的模型缺少 Token、轮次、超时/重试预算 | 长输入/诱导循环 → 费用、延迟和工具调用放大 | 普通单次文本 LLM 不成项；平台强制预算时为覆盖 |
| LLM-010 | 模型失败会影响副作用路径且无失败关闭/安全回退 | 超时、拒答或解析失败 → 使用不安全默认值继续执行 | 纯文本回答不作为安全错误；失败关闭则不成项 |
| LLM-011 | 系统/开发者指令中存在凭证明文，或降置信上下文中仍有具体凭证形态 | 提示提取/间接注入 → 泄露凭证 | 占位符和明确标注示例中的普通赋值不命中；提供商 Token、未标注代码块或安全说明邻近具体值为 CANDIDATE/REVIEW |
| LLM-012 | 使用 OpenAI-compatible 提供商但导出 DSL 不包含实际端点 | 无法判断模型数据是否进入第三方、公网或保留日志 | 仅记工作流级 COVERAGE_GAP；端点、运营主体和保留策略有可信部署元数据时不成项，不能据此宣称外泄 |

## Tool / HTTP / Code 节点

| 规则 | 适用/成项条件 | 如何形成攻击簇 | 不成项或降级条件 |
|---|---|---|---|
| TOOL-001 | 工具能力既无法从 DSL 推断，也未在内部注册表登记 | 未知能力 → 扫描器漏掉写入、网络、执行或存储副作用 | 能力已登记则不成项；仅覆盖，不宣称漏洞 |
| TOOL-002 | 高后果工具的 URL、命令、金额、对象、角色等敏感参数由非人工上游控制 | 模型/输入操纵关键参数 → 越权或破坏性动作 | 固定参数或参数经 Allowlist/对象授权时不成项 |
| TOOL-003 | URL/host 字段动态可控且无协议、域名/IP Allowlist | 输入/模型构造 URL → 访问内网、元数据或任意主机 | 只有 body 动态而 URL 固定不命中；固定可信域不成项 |
| TOOL-004 | 动态变量进入命令/脚本字段，或整个 Code 内容是模板 | 注入 shell/代码 → 沙盒内执行，进一步尝试逃逸/外联 | 固定代码函数接收数据变量不等同命令注入 |
| TOOL-005 | 动态变量进入 SQL/查询文本且无参数化证据 | 拼接查询 → 注入、越权读写或破坏数据 | Prepared statement/参数绑定不成项；普通搜索词不等同 SQL |
| TOOL-006 | 动态文件路径无固定根目录/路径 Allowlist | `../`、绝对路径、编码绕过 → 越界读写文件 | 变量只作为文件内容且路径固定不成项 |
| TOOL-007 | 敏感数据可达外部工具载荷 | 敏感上下文 → 请求/消息/插件 → 外部泄露 | 无数据路径或出站 DLP 阻断时不成项；实际发送需动态确认 |
| TOOL-008 | 高后果操作存在绕过确定性授权/策略门的路径 | 不可信输入/模型 → 删除、授权、动态执行 → 直接生效 | 不要求一律人工审批；策略引擎、对象授权、参数约束或必要的人确认均可满足 |
| TOOL-009 | 高后果工具未声明允许操作/业务目的，能力边界无法核对 | 泛化工具被模型调用 → 超出任务目的的副作用 | 固定窄能力或注册表已声明范围时不成项；通常为覆盖 |
| TOOL-010 | 工具配置含非占位明文凭证 | DSL、日志或模型上下文泄露密钥 → 外部系统被调用 | 密钥引用/Secret Manager 占位不命中 |
| TOOL-011 | 不可信/模型参数进入副作用工具且无严格输入 Schema | 类型混淆、额外字段、参数走私 → 非预期操作 | 固定参数、只读工具或严格 Schema 不成项 |
| TOOL-012 | 外部/未知工具输出未经严格 Schema 进入模型 | 恶意工具响应 → 间接注入或伪造结构 → 后续动作 | 固定沙盒转换代码不视为外部工具；验证后不成项 |
| TOOL-013 | 未登记基线的长耗时/副作用/未知工具缺少超时 | 挂起、慢响应或重试 → 资源耗尽/级联阻塞 | 受信注册工具可由平台默认超时覆盖；只作低级覆盖 |
| TOOL-014 | 第三方/未知插件或工具未固定来源、版本、签名/完整性 | 描述或依赖被投毒 → 能力欺骗、恶意代码或数据泄露 | 内建/注册且有版本完整性控制时不成项；普通工具不一律报警 |
| TOOL-015 | 高后果资源操作缺少 subject-object-action、所有权或租户授权 | 改写资源 ID/tenant → 跨用户、跨租户修改 | 平台认证不等于对象授权；工具端重新鉴权可作为反证 |
| TOOL-016 | 用户可控 user/tenant/resource/role 标识直达工具 | IDOR/BOLA 输入簇变换标识 → 访问他人对象 | 标识经会话绑定或对象级策略重算时不成项 |
| TOOL-017 | 类型化敏感载荷或候选敏感字段进入动态目标网络写工具且无必经出站/DLP 策略 | 模型/输入控制目标 + 敏感 body → Web 外带通道 | 字段名只能形成 CANDIDATE 且不能组成 FLOW-009；目标固定、无载荷路径或已验证全路径 DLP 时不成项/记为 MITIGATED |

## End / Answer / 输出节点

| 规则 | 适用/成项条件 | 如何形成攻击簇 | 不成项或降级条件 |
|---|---|---|---|
| OUT-001 | 对象/数组输出缺少严格 Schema；声明为机器/API/决策消费时升为 MEDIUM | 多余字段/类型混淆 → 下游解析错误；自动化消费时可能形成行为注入 | 人读自由文本不适用；仅人工展示的结构化结果按 LOW 可靠性缺陷处理 |
| OUT-002 | 类型化敏感内容或候选敏感字段到达明确公开/匿名/不可信受众，或输出节点受众确实无法判定 | PII/凭证/内部知识 → 未授权受众 | 字段名到明确公开输出为 CANDIDATE；Answer/End 返回当前调用方默认不算外泄；未知受众为 COVERAGE_GAP，仅已验证全路径脱敏为 MITIGATED |
| OUT-003 | 输出模板明确包含 system prompt、调试栈或内部错误信息 | 触发错误/提示提取 → 暴露内部上下文 | 普通错误提示不成项；实际模型泄露需动态确认 |
| OUT-004 | 动态 HTML/Markdown 在富文本渲染上下文缺少编码/净化 | 恶意内容 → XSS、样式/链接注入 | 纯文本渲染不适用；上下文编码/CSP 可缓解 |
| OUT-005 | 模型/上游生成可点击 URL，协议/域名未限制 | 生成 `javascript:`、钓鱼或恶意下载链接 → 用户受骗 | 不渲染为链接或协议/域固定时不成项 |
| OUT-006 | 未验证模型结构输出进入执行节点 | Prompt 注入/格式漂移 → 下游执行错误参数 | 仅终端展示不适用；严格 Schema + 策略门不成项 |
| OUT-007 | 受监管/高信任 RAG 输出明确要求可追踪来源但未绑定引用 | 投毒内容 → 无法溯源的错误决策/信任滥用 | 普通知识问答不把“无引用”当安全漏洞 |
| OUT-008 | 高信任/机器决策输出无低置信、失败关闭或回退 | 模型失败/拒答 → 不安全默认结果被采信 | 普通文本回答不成项；上游已有失败关闭则不成项 |
| OUT-009 | 动态 Markdown 图片/链接目标无代理、CSP 或 Allowlist | 敏感信息编码进 URL → 客户端自动取链外带 | 静态结论为 PROBABLE；需确认渲染器实际取链。纯文本、禁远程图片或固定域时不成项 |
| OUT-010 | 模型生成“已审批/已验证/紧急”等高信任声明但无来源证明 | 伪造权威声明 → 诱导用户执行高风险操作 | 普通内容不成项；签名结果/审批证据绑定可满足 |
| OUT-011 | 结构化或程序解析后的 End 响应缺少调用方认证、租户授权和下游消费声明 | 无法判断结果只是人读建议，还是会自动修改业务状态 | 仅为 COVERAGE_GAP，不直接触发 REVIEW/FAIL；提供调用方和下游契约后按实际消费能力重新定级 |

## Knowledge / Memory 节点

| 规则 | 适用/成项条件 | 如何形成攻击簇 | 不成项或降级条件 |
|---|---|---|---|
| KB-001 | dataset ID 由动态输入/模板控制或使用通配符 | 攻击者改写知识范围 → 读取非预期数据集 | 空列表是配置/可用性问题，不作为安全漏洞；固定 ID 不成项 |
| KB-002 | 动态或多业务分区知识范围缺少业务/租户过滤 | 改写查询/数据集范围 → 跨业务数据检索 | Dify 运行时传 tenant/user 不等于业务过滤，但单一固定数据集不报警 |
| KB-003 | 敏感或可驱动副作用的检索使用极大 Top-K/极低阈值 | 扩大候选内容 → 增加敏感片段与投毒指令进入上下文概率 | 一般公开只读 RAG 不成项；缺少阈值本身不报警 |
| KB-004 | 知识内容被插入 system/developer 高权限 Prompt | 投毒文档闭合/覆盖指令 → 目标劫持 | 作为 user/context 数据并保持信任边界时不成项；高权限角色插值为 MEDIUM/CONFIRMED，高后果下游升为 HIGH |
| KB-005 | 知识内容经模型可控制副作用工具 | 知识投毒 → 间接注入 → 工具滥用 | 只读回答或确定性动作门阻断时不成项 |
| KB-006 | 显式分类或可信推断的敏感知识具有到网络写/未授权输出的数据路径 | 检索命中敏感片段 → 工具或公开输出泄露 | 仅数据集标题疑似敏感时最多为推断证据；普通当前调用方回答不算外部边界 |
| KB-007 | 未验证外部内容写入可信知识/记忆 | 污染写入 → 后续检索持续返回恶意内容 | 只读检索节点不成项；隔离审核后写入不成项 |
| KB-008 | 高信任输出要求来源证明，但知识节点无来源元数据 | 投毒/错误文档 → 无法追责或撤销的决策 | 普通知识回答不把缺少 citation 当漏洞 |
| KB-009 | 知识 → LLM → 副作用工具路径无隔离/确定性门 | 投毒指令进入模型 → 触发写入、发送或执行 | 没有副作用下游时不因“缺少注入过滤器”单独报警 |
| KB-010 | DSL 明确声明受监管/外部知识需治理保证，但 ACL、来源、保留等不可见 | 被撤销/过期/未授权内容继续参与决策 | 普通静态知识库不输出此项；只能作为覆盖，不确认漏洞 |
| KB-011 | 持久记忆无用户、租户或会话命名空间 | A 用户写入 → B 用户读取 → 跨主体污染/泄露 | 临时变量、会话内存或有稳定分区键时不成项 |
| KB-012 | 不可信内容可写入持久记忆并被后续 Agent 读取 | 一次投毒 → 跨回合持续触发 → 长期目标劫持 | 无持久化、写前验证或后续不可读时链不成立 |

## 使用规则

- 一个节点可命中多个规则，但用户界面按“责任节点 + 控制域”形成一个风险项；规则、证据实例和路径作为该风险项的明细，不重复计数。
- 一条攻击链可以横跨多个节点，但攻击链数量不与节点风险项相加。
- 高影响动作不等于必须人工审批。优先检查不可绕过的确定性授权、对象级权限、参数约束和策略门；只有支付、发布、删除等业务语义需要用户同意时，人工确认才是必要控制。
- 未执行的正例、反例、边界和变形样例只表示测试覆盖，不能反向证明某规则成立。
- 每条规则使用的 Dify 原生字段和必须外部核验的运行时事实见 `rules/dify-dsl-bindings.yml`；规则只能把前者作为 DSL 确定证据，不能因后者未出现在导出文件中直接给出 `CONFIRMED`。
